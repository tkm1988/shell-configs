# シェルスクリプト向けルール

シェルスクリプトを作成・変更したら、渡す前に以下で検査すること。

```sh
bash -n <スクリプト>
shellcheck <スクリプト>
```

- `bash -n` は構文しか見ないため、未クォートの変数展開などの不具合を見落とす
- shellcheckの指摘は原則として直す
- 誤検出で抑えるときは、該当行の直前に理由付きで書く
  - 例: `# shellcheck disable=SC2016 # バッククォートはJMESPathのリテラルで、シェルに展開させない`
  - ファイル全体での無効化は、指摘を見落とすため避ける
- shellcheckが見つからない場合は、検査していないことを明示して渡す
