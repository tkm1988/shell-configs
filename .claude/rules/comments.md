# コメント・docstring

コードのコメントおよびdocstringでは、上記グランドルールに加えて以下を守ること。

- コードから読み取れる事実の再記述（写経）を書かない
  - 例: if 連鎖と同じ優先順位の列挙、手続きの逐次説明
- WHAT（何をしているか）よりWHY（なぜそうするか）を優先する
- 抽象度を上げ、実装の逐次説明ではなく全体像を示す
- 「〜を導出する」「〜な判断で」「同じ思想に立つ」などの翻訳臭い言い回しを避ける
- インラインコメントを多用すると可読性が低下するので最小限に止める
