# Emacs 操作手引き

`~/.emacs.d/init.el`（2026-09-03 版）の使い方をまとめます。Emacs 31.1 と端末での利用を前提にしています。

## 1. 思い出せないときの 4 手

| 知りたいこと         | 操作                                                  |
| -------------------- | ----------------------------------------------------- |
| プレフィクスの続き   | `C-c` や `C-x` を押して 0.7 秒待つ（which-key が出る） |
| コマンド名から探す   | `M-x`（履歴と使用頻度の順に並ぶ）                     |
| このキーの割り当て   | `C-h k` を押してから対象のキー                        |
| このコマンドのキー   | `C-h w` を押してからコマンド名                        |

which-key を入れてあるため、`C-c` だけ押して待てば下表の内容がその場で出ます。

## 3. 機能別のキー一覧

### 3.1 検索

| キー      | コマンド             | 補足                                 |
| --------- | -------------------- | ------------------------------------ |
| `C-s`     | swiper               | バッファ内検索。候補が一覧表示される |
| `C-c s`   | rg-menu              | ripgrep。対象や除外をメニューで選ぶ  |
| `M-s i`   | counsel-imenu        | ファイル内の定義や見出しの一覧       |
| `C-x p g` | project-find-regexp  | プロジェクト内検索（組み込み）       |
| `C-x p f` | project-find-file    | プロジェクト内のファイル探索         |

swiper の実行中に `C-c C-o` を押すと、候補を専用バッファへ出せます。

### 3.2 移動

| キー       | コマンド               | 補足                                       |
| ---------- | ---------------------- | ------------------------------------------ |
| `M-g w`    | avy-goto-char-timer    | 文字を打つとラベルが出る。ラベルのキーで飛ぶ |
| `M-g g`    | avy-goto-line          | 行番号の入力も受ける（goto-line の代わり） |
| `<f12>`    | xref-find-definitions  | 定義へ                                     |
| `S-<f12>`  | xref-find-references   | 参照の一覧                                 |
| `M-<f12>`  | xref-go-back           | 飛ぶ前の位置へ戻る                         |
| `C-x C-r`  | counsel-recentf        | 最近開いたファイル（500 件保持）           |
| `C-x C-j`  | dired-jump             | 編集中のファイルがある場所を開く           |

### 3.3 編集

| キー              | コマンド                    | 補足                                             |
| ----------------- | --------------------------- | ------------------------------------------------ |
| `C-c =` / `C-c -` | expreg-expand / contract    | 構文単位で選択範囲を広げる・狭める               |
| `M-i`             | symbol-overlay-put          | 同じシンボルを色付きで強調する                   |
| `C-c i`           | string-inflection-all-cycle | snake_case、CamelCase、camelCase を順に切り替える |
| `C-_`（`C-/`）    | undo-fu-only-undo           | 端末は `C-/` を `C-_` として送る                 |
| `M-_`             | undo-fu-only-redo           | 履歴は再起動後も残る                             |
| `C-x u`           | vundo                       | undo 履歴を木で表示し、左右のキーで辿る          |
| `M-+` / `M-*`     | tempel-complete / insert    | テンプレート展開。現状は候補が空（第 6 章）      |

#### M-i の後は文字キーがコマンドになります

`M-i` で強調した語の上にカーソルがある間、次のキーはコマンドとして働きます。文字を入力したいときは強調の外へ移るか、`i` で解除します。

| キー      | 動作                             |
| --------- | -------------------------------- |
| `n` / `p` | 次・前の同じ語へ                 |
| `<` / `>` | 最初・最後の同じ語へ             |
| `r`       | 同じ語をまとめてリネーム         |
| `q`       | 問い合わせ付きで置換             |
| `d`       | 定義へ                           |
| `i`       | 強調を解除                       |
| `h`       | このキー一覧を表示               |

0.5 秒静止すると同じ語が薄く強調されますが、そちらにキー操作は付きません。

### 3.4 補完（company）

2 文字打つと即座に候補が出ます。

| キー          | 動作                                 |
| ------------- | ------------------------------------ |
| `C-n` / `C-p` | 候補を選ぶ                           |
| `RET`         | 確定                                 |
| `TAB`         | 共通部分を補ってから候補を巡る       |
| `C-g`         | 候補を消す                           |
| `M-h`         | 選択中の候補の説明を見る             |

候補が出ている間は `RET` が確定になります。改行したいときは `C-g` で候補を消してから押します。

### 3.5 ミニバッファ（ivy）

| キー          | 動作                                             |
| ------------- | ------------------------------------------------ |
| `C-n` / `C-p` | 候補を選ぶ                                       |
| `RET`         | 決定                                             |
| `C-M-j`       | 入力した文字列のまま決定（新規ファイル名など）   |
| `TAB`         | 共通部分を補う                                   |
| `M-o`         | 決定の代わりに別の動作を選ぶ（別ウィンドウ等）   |
| `C-c C-o`     | 候補を専用バッファへ出す                         |
| `C-o`         | 操作メニュー（hydra）                            |
| `M-n` / `M-p` | 入力履歴を辿る                                   |

先頭のプロンプト行そのものも選択できます。履歴は再起動後も残ります。

### 3.6 ファイルとディレクトリ（dirvish）

| キー    | コマンド      | 補足                                 |
| ------- | ------------- | ------------------------------------ |
| `C-c d` | dirvish-dwim  | 親・現在・プレビューの 3 分割        |
| `C-c D` | dirvish-side  | 左サイドバー（幅 35）                |
| `q`     | dirvish-quit  | 閉じる                               |

中身の操作は dired と同じです。

| キー            | 動作                                 |
| --------------- | ------------------------------------ |
| `RET`           | 開く                                 |
| `^`             | 親ディレクトリへ                     |
| `m` / `u` / `t` | マーク・解除・反転                   |
| `C` / `R` / `D` | コピー・リネーム・削除（ゴミ箱へ）   |
| `+`             | ディレクトリを作る                   |
| `g`             | 表示を更新                           |
| `M-=`           | difftastic で 2 ファイルを比較       |

ディレクトリが先頭に並ぶよう ls-lisp を使っています。ディレクトリを辿ってもバッファは増えません。メニューは `M-x dirvish-dispatch` で開きます。

### 3.7 Git（magit）

| キー    | 動作                     |
| ------- | ------------------------ |
| `C-x g` | magit-status を開く      |

status バッファの中は次のキーで操作します。

| キー          | 動作                       |
| ------------- | -------------------------- |
| `?`           | 使えるキーの一覧           |
| `TAB`         | 対象の開閉                 |
| `s` / `u`     | ステージ・解除             |
| `c c`         | コミット                   |
| `d`           | 差分メニュー               |
| `l l`         | ログ                       |
| `b b`         | ブランチ切り替え           |
| `P p` / `F p` | push・pull                 |

構文を理解する差分（difftastic）は magit の中から呼びます。

| 場所                   | キー                          |
| ---------------------- | ----------------------------- |
| 差分メニュー（`d`）内  | `M-d` で差分、`M-c` で show   |
| blame 中               | `M-RET`                       |
| dired 内               | `M-=`                         |

変更行は diff-hl が示します。端末にはフリンジが無いため、左余白に印が出ます。

### 3.8 コードジャンプと診断（eglot / flymake）

| キー                            | 動作                             |
| ------------------------------- | -------------------------------- |
| `<f12>` / `S-<f12>` / `M-<f12>` | 定義・参照・戻る                 |
| `<f2>`                          | シンボル名の変更（LSP のみ）     |
| `C-c a`                         | コードアクション                 |
| `C-c f`                         | バッファ全体を整形               |
| `<f8>` / `M-<f8>`               | 次・前の問題へ                   |
| `C-c !`                         | プロジェクト全体の診断一覧       |

LSP は言語サーバーの実行ファイルが見つかるときだけ自動で起動します。起動していればモードラインに `EGLOT` が出ます。出ないときは `M-x eglot` で手動起動できます。

### 3.9 SQL と Markdown

| キー      | 対象       | 動作                                       |
| --------- | ---------- | ------------------------------------------ |
| `C-c C-f` | sql-mode   | pg_format で整形する（保存時には走らない） |
| `<f8>`    | markdown   | textlint の指摘を順に辿る                  |

Markdown は保存時に自動整形されます（第 5 章）。SQL のインデントは sql-indent が構文に沿って揃えます。

### 3.10 ブラウザ

| キー        | 動作                                     |
| ----------- | ---------------------------------------- |
| `C-c u`     | カーソル位置の URL を chawan で開く      |
| `C-c U`     | URL を入力して開く                       |
| `C-u C-c u` | OS の既定ブラウザで開く                  |
| `C-c w`     | eww で開く（検索は DuckDuckGo）          |

tmux の中では chawan が新しい tmux ウィンドウで開きます。tmux の外では term バッファで動きます。`cha` が無い環境では eww に切り替わります。

### 3.11 LLM（gptel）

| 操作                | 動作                             |
| ------------------- | -------------------------------- |
| `M-x gptel`         | チャット用のバッファを作る       |
| `C-c RET`           | 送信（gptel のバッファ内）       |
| `M-x gptel-send`    | 選択範囲を送る                   |
| `M-x gptel-menu`    | モデルや送信範囲を変える         |

モデルは Gemini の `gemini-pro-latest` です。API キーは `~/.authinfo.gpg` の次の行から読みます。

```text
machine generativelanguage.googleapis.com login apikey password <API_KEY>
```

## 5. 保存したときに自動で起きること

| 対象                  | 起きること                                                              |
| --------------------- | ----------------------------------------------------------------------- |
| `~/.emacs.d/init.el`  | init.elc を作り直す。失敗したときは init.elc を削除して結果を知らせる   |
| `*.md`                | textlint --fix の後に prettier で整形する                               |
| その他のファイル      | 整形しない                                                              |

Markdown の整形はプロジェクトの `node_modules/.bin` にある textlint と prettier を使います。導入されていないディレクトリでは整形されません。`~/.emacs.d` 直下も対象外です。

terraform と SQL の保存時整形はどちらも無効です。有効にする手順は第 6 章にあります。

## 6. 未整備の点と有効化の方法

| 項目                        | 現状                                                              | 有効にする方法                                                        |
| --------------------------- | ----------------------------------------------------------------- | --------------------------------------------------------------------- |
| tempel のテンプレート       | `~/.emacs.d/templates` が無いため `M-+` の候補が空                | 同ディレクトリにテンプレートファイルを置く                            |
| dirvish のクイックアクセス  | `~/`、`~/.emacs.d/`、`~/GitHub/Work/` を登録済みだが呼び出しキーが無い | `M-x dirvish-quick-access` を使う、または好みのキーに割り当てる       |
| dirvish のサブツリー展開    | 表示属性は有効だが開閉のキーが無い                                | `M-x dirvish-subtree-toggle` を使う                                   |
| terraform の保存時整形      | 無効                                                              | terraform コマンドを通した後 `terraform-format-on-save` を `t` にする |
| SQL の保存時整形            | 無効                                                              | `sql-mode-hook` に `sqlformat-on-save-mode` を足す                    |
| Rust の LSP                 | 対象外（rustup のプロキシが起動に失敗するため）                   | toolchain を入れた後 `my:eglot-server-executables` に追加する         |

## 7. 素の Emacs から変えた挙動

キー操作ではなく、常に効いている設定です。

| 挙動                                             | 仕組み                    |
| ------------------------------------------------ | ------------------------- |
| 選択範囲があるときに入力すると置き換わる         | delete-selection-mode     |
| camelCase を単語単位で移動する                   | subword-mode              |
| 削除したファイルはゴミ箱へ入る                   | delete-by-moving-to-trash |
| yes / no の質問に y / n で答える                 | use-short-answers         |
| 終了時に確認が入る                               | confirm-kill-emacs        |
| `~` のバックアップと自動保存を作らない           | backup-inhibited          |
| 外部で変わったファイルを黙って読み直す           | global-auto-revert-mode   |
| ファイルを開くと前回のカーソル位置に戻る         | save-place-mode           |
| ミニバッファの履歴が再起動後も残る               | savehist-mode             |
| undo 履歴が再起動後も残る                        | undo-fu-session           |
| 極端に長い行のファイルでも固まらない             | so-long-mode              |
| 現在行がハイライトされる                         | global-hl-line-mode       |
| 端末から `emacsclient -n <file>` で開ける        | server-start              |

プログラムを書くモードでは、行番号、インデントの縦線、括弧の色分け、ヘッダ行のパンくずが加わります。配色は modus-vivendi です。

## 9. 困ったときの確認

| 症状                             | 確認すること                                                            |
| -------------------------------- | ----------------------------------------------------------------------- |
| 設定を変えたのに反映されない     | init.el の保存直後のメッセージを見る。「init.elc を更新しました」が成功 |
| 起動しなくなった                 | `rm ~/.emacs.d/init.elc` の後、`emacs -Q` で切り分ける                  |
| キーが効かない                   | `C-h k` で実際に届いているキーを見る。下表のキーは端末に届かない        |
| LSP が動かない                   | モードラインの `EGLOT` を見る。無ければ `M-x eglot`                     |
| textlint の指摘が出ない          | そのプロジェクトに textlint が入っているかを確認する                    |
| 別の端末から今の Emacs に開きたい | `emacsclient -n <file>` を使う                                          |

### 端末で使えるキーの区分

| 種類                              | 可否                           |
| --------------------------------- | ------------------------------ |
| `C-<英字>`                        | 使える                         |
| `C-<記号>`（`.` `=` `:` `'` `?`） | 使えない                       |
| `C-/`                             | `C-_` として届く               |
| `C-S-<英字>`                      | 使えない（Shift が落ちる）     |
| `M-<英字>`、`M-<記号>`            | 使える                         |
| F キー、`S-F`、`M-F`              | 使える                         |
| `C-c`、`C-x` の配下               | 使える                         |

この制約のため、記号を含む割り当ては `C-c` 配下と `M-g` 配下へ寄せてあります。

## 10. ファイルの構成

| ファイル              | 役割                                             |
| --------------------- | ------------------------------------------------ |
| `init.el`             | 手書きの設定。編集するのはここだけ               |
| `init.elc`            | init.el のコンパイル結果。保存時に自動更新       |
| `custom.el`           | Customize が書き込む設定の置き場                 |
| `var/`                | 履歴、カーソル位置、undo などの保存先            |
| `REPORT-20260826.md`  | 2026-08-26 のリファクタリング作業報告            |
